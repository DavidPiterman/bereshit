# בראשית

מוח קטן שנולד בדפדפן שלך ולומד עברית מאפס, מול העיניים.

**לצפייה: https://davidpiterman.github.io/bereshit/**

כשלוחצים "יהי אור", רשת נוירונים קטנה (טרנספורמר של כ-600 אלף פרמטרים) מתחילה ממשקלים אקראיים וקוראת את חמשת חומשי התורה שוב ושוב, כשהמשימה היחידה שלה היא לנחש את האות הבאה. האימון רץ על כרטיס המסך של מי שצופה, בזמן אמת. אין הקלטה, ואף ריצה לא חוזרת על עצמה.

מה רואים:

- **המגילה**: מה שהמוח כותב כרגע. אפור הוא לא־מילה, זהב הוא מילה שקיימת בתורה, טורקיז הוא רצף שהוא זוכר מהתורה, וקו תחתון מסמן פסוק שלם שלא נכתב מעולם.
- **המוח**: 1,536 נוירונים בשלוש שכבות. כל הבהוב הוא חישוב אמיתי של האות הנוכחית. הקשתות מראות לאילו אותיות קודמות הוא מסתכל.
- **ימי הבריאה**: אבני דרך שנמדדות מהפלט עצמו, מ"תוהו ובוהו" ועד שבעה פסוקים משלו.

מה אפשר לעשות: לדבר איתו, לשנות לו את החום, לרחף מעל נוירון ולראות על מה הוא נדלק, לכבות נוירונים ולראות אותו משתקם, ולהאכיל אותו בטקסט אחר.

עובד הכי טוב במחשב עם Chrome או Edge.

## איך זה בנוי

קובץ HTML אחד. האימון נעשה עם TensorFlow.js על WebGL. הקריאה והתצוגה של הנוירונים נעשות במעבר קדימה שנכתב ביד ב-JavaScript, אות אחר אות. המקורות בתיקייה `build/`, ו-`node build/build.js` מרכיב מהם את `index.html`.
